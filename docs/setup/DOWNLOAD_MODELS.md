# How to download the model weights

This repository does NOT distribute the `.tflite` weights due to licensing.

To run the biometric verification, you need to download:
1. `facenet.tflite` (or any FaceNet 160px TFLite model).
2. `blaze_face_short_range.tflite` (from the official MediaPipe repo).

Place both files in the root directory of this project.
