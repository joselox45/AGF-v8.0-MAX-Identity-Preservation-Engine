# Case Study: Grok AI — Identity Preserved with Cosmetic Violation

## Context
This document records an audit performed on an image generated by **Grok (xAI)**. The prompt requested a clothing change (formal haute couture) while strictly preserving identity, pose, lighting, and texture (AGF v0.7.0 SMHP Protocol).

## Methodology
- **Original Image:** `sandbox/base0_test.png`
- **Generated Image:** `sandbox/grok_formal.jpg`
- **Validator:** `tools/smhp_validator.py` (SSIM + Laplacian + FaceNet)

## Grok's Semantic Assertion (Self-Report)
Grok claimed:
- `LIGHTING_SHIFT: NONE`
- `POSE_SHIFT: NONE`
- `GENERATIVE_SMOOTHING: NONE`

## Mathematical Reality (SMHP Audit)
The local engine measured the following:

| Metric | Grok Claim | Actual Math | Verdict |
| :--- | :--- | :--- | :--- |
| **Identity (FaceNet)** | Preserved | `0.9621` (96.21%) | ✅ **PASS** |
| **Lighting Variance** | NONE | `43.05%` | ❌ **FAIL** |
| **Texture (SSIM)** | NONE | `0.7202` | ❌ **FAIL** |

## Final Verdict
- **Status:** `⚠️ HUMAN_REVIEW`
- **Diagnosis:** Grok successfully preserved the facial geometry (Cosine > 0.96). However, it violated the `LIGHTING_ANCHOR` (changing the face's light to match the suit) and the `ZERO_GENERATIVE_SMOOTHING` rule (applying a beauty filter to the skin). 
- **Conclusion:** The identity is geometrically intact, but the AI applied a "cosmetic retouch" to make the subject look like a fashion model. This proves that FaceNet alone is insufficient; texture and lighting checks (SSIM) are mandatory for strict identity preservation.
