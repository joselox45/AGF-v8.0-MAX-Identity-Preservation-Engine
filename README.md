## Architecture and Layers
The system operates on 6 verification layers to guarantee absolute integrity:

1.  **Deep Learning (FaceNet TFLite):** Real biometric verification (Cosine Similarity).
2.  **Classical CV (OpenCV/BlazeFace):** Deterministic face detection and alignment.
3.  **Math Vectors (NumPy/SciPy):** Pixel analysis (Euclidean Distance, SSIM, Laplacian Variance).
4.  **Pixel Hash PIXEL_LOCKED:** SHA-256 per 32x32 facial tile. No orphan tiles allowed (SSIM threshold 0.92).
5.  **Limbal Ring Adaptive Engine:** Evaluates Loss, Incentive, and Evidence. Abort Rule: Revert if metrics fail.
6.  **Classic Restoration:** Mathematical filters only (Median, UnsharpMask, Gaussian, Dehaze).
