## Architecture and Layers
The system operates on 5 verification layers to guarantee integrity:

1.  **Deep Learning (FaceNet TFLite):** Real biometric verification (Cosine Similarity).
2.  **Classical CV (OpenCV/Haar Cascade):** Classical face detection and alignment (`tools/forensic_analyzer.py`).
3.  **Math Vectors (SciPy/NumPy):** Mathematical analysis of pixels (Euclidean Distance and full-image Cosine).
4.  **Limbal Ring (v9.0):** Decision engine that evaluates Loss, Incentive, and Evidence before applying any filter (`src/agf_v9_limbal.py`).
5.  **Classic Restoration:** Mathematical filters without generative AI (`tools/classic_restorer.py`).
